# Project instructions

This is a mobile-first Chinese medical education webpage.

## Style
- Keep the tone plain, direct, and easy to understand.
- Avoid generic AI-style phrases such as “首先、其次、最后、总之”.
- Prefer examples over abstract explanations.
- Use short paragraphs for mobile reading.

## Code
- Keep it static HTML/CSS unless explicitly asked otherwise.
- Do not add React, Vue, Tailwind, or build tools unless requested.
- Keep CSS readable and self-contained.
- Optimize for mobile width first.

## Content
- This is general health education, not medical diagnosis.
- Keep warnings clear but not alarmist.
